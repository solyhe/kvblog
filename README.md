# 日志博客

基于 **Cloudflare Workers + KV** 的轻量个人博客，单文件部署，零成本运行。

## 功能特性

- 📝 在线 Markdown 编辑器，实时预览
- 🏷️ 标签分类与标签过滤
- 📄 文章分页（每页 10 篇）
- 📊 访问统计与浏览量
- 📎 附件上传（图片 / 文件，支持拖拽粘贴上传）
- 📖 文章目录（TOC）自动生成 + 滚动高亮
- 🎨 阅读进度条、返回顶部
- 🔐 后台管理（登录、文章 CRUD、草稿/发布）
- 📱 响应式布局，移动端适配
- ⚡ 纯服务端渲染，无外部框架依赖

## 部署步骤

### 1. 创建 KV 命名空间

登录 Cloudflare → **Workers & Pages → KV** → 创建命名空间，记录名称。

### 2. 绑定 KV

进入 Worker → **设置 → 绑定 → KV 命名空间绑定**：

| 变量名称 | 选择 |
|----------|------|
| `BLOG` | 刚创建的 KV 命名空间 |

### 3. 配置环境变量（可选，推荐）

在 Worker **设置 → 变量**中配置，覆盖默认值：

| 变量名 | 默认值 | 说明 |
|--------|--------|------|
| `ADMIN_USER` | `admin` | 后台登录账号 |
| `ADMIN_PASS` | `admin888` | 后台登录密码 |

> ⚠️ **上线前务必修改默认密码！**

### 4. 粘贴代码

将 `index.js` 全部内容粘贴到 Worker 编辑器中，保存部署即可。

## 路由说明

### 前台

| 路由 | 方法 | 说明 |
|------|------|------|
| `/` | GET | 首页（文章列表、标签过滤、搜索） |
| `/post/:id` | GET | 文章详情页 |
| `/attach/:id/:fn` | GET | 附件 / 图片访问 |

### 后台

| 路由 | 方法 | 说明 |
|------|------|------|
| `/admin/login` | GET | 登录页 |
| `/admin/login` | POST | 登录提交 |
| `/admin/logout` | POST | 退出登录 |
| `/admin` | GET | 后台管理（统计 + 文章列表） |
| `/admin/edit` | GET | 写 / 编辑文章 |
| `/admin/save` | POST | 保存文章 |
| `/admin/delete` | POST | 删除文章 |
| `/admin/upload` | POST | 上传附件 |
| `/admin/attach-delete` | POST | 删除附件 |

## 后台操作

1. 访问 `/admin/login`，输入账号密码登录
2. 登录后进入 `/admin`，可看到统计卡片（全部文章 / 已发布 / 草稿 / 总浏览量）
3. 点击 **「+ 写新文章」** 进入编辑器
4. 编辑器支持：
   - 标题、标签、发布开关
   - 工具栏快捷插入（粗体、斜体、标题、列表、引用、代码块、表格、链接等）
   - 实时 Markdown 预览
   - **拖拽图片 / 粘贴图片** 自动上传并插入
   - `Ctrl+S` 保存，`Ctrl+B` 粗体，`Ctrl+I` 斜体
   - Tab 缩进，Enter 自动续列表
5. 保存后：
   - 开关打开 → 已发布，前台可见
   - 开关关闭 → 草稿，前台不显示

## KV 数据结构

| Key 格式 | 内容 |
|----------|------|
| `index` | 所有文章 ID 数组（JSON） |
| `post:{id}` | 单篇文章对象（标题、内容、标签、时间、浏览量、发布状态） |
| `attachments:{id}` | 该文章的附件文件名列表（JSON 数组） |
| `attach:{id}:{filename}` | 附件内容（base64 DataURL） |

## 注意事项

- 附件以 base64 存储在 KV 中，**单条 KV value 上限 25MB**，建议单图控制在 2MB 以内
- Session 基于账号密码派生，修改密码后旧会话自动失效
- 文章 ID 由时间戳 + 随机串生成，无需手动维护
- 免费版 Workers / KV 有每日请求限额，适合个人博客使用
- 前台搜索为客户端过滤，仅在当前页范围内匹配
